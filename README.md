# Headroom

**know your headroom**

A personal psychological load management tool built on the stress-bucket model used in CBT and addiction recovery.

Public website and PWA prototype at [headroom.me.uk](https://headroom.me.uk).

## Stack

- Node.js 20.x (pinned)
- Express
- Static frontend (no build step)

## Local development

```bash
npm install
node server.js
```

Server runs on `http://localhost:3000`.

## Deployment

Hosted on [Render](https://render.com). Domain on Cloudflare (DNS-only CNAME).
